# The Deadman Show

A YouTube podcast where the host (Ram) interviews AI recreations of historical figures,
grounded in their own writings. This repo holds the pipeline and every episode.

- **Rules and voice:** `show/bible.md`. Read it before writing or reviewing anything.
- **Make an episode:** `/new-episode <figure>` (researcher → scriptwriter → fact-checker
  agents in `.claude/agents/`). Add a new guest with `/add-figure <name>`.
- **Episodes:** `episodes/NNN-<slug>/`. `transcript.md` and `packaging.toml` are the source
  of truth; `script.md`, `youtube-description.txt` and `episode.json` are generated by
  `python -m deadman render <NNN>`. Never edit generated files by hand.
- **Checks:** `python -m deadman check <NNN>` must report 0 errors before rendering.
  Direct quotes must be verbatim from a cited passage (`python -m deadman show <figure> <id>`).

## Setup in a fresh session

```bash
pip install -r requirements-dev.txt
python -m deadman ingest adam_smith     # data/ is not committed; ingest each figure you need
python -m pytest
```

The `episode` and `script` commands call the Claude API and need `ANTHROPIC_API_KEY`.
Without a key, episodes are made in-session with the skills and agents above.
